# Vela Pictures Website

Initial static website for Vela Pictures.

## Files

- `index.html` — page structure and copy
- `style.css` — responsive design and animation
- `script.js` — intro, navigation, and reveal behavior
- `assets/` — Vela brand imagery

## Deploying to Vercel

This is a static site. Vercel should detect it automatically with:

- Framework preset: **Other**
- Root directory: `./`
- Build command: leave blank
- Output directory: leave blank

## Notes

The current film-card imagery is loaded from Unsplash. Replace those URLs with licensed or original Vela Pictures assets before a formal commercial launch.
